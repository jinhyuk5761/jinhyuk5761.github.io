## 3. 앱 콘텐츠 (필수 설문)

### 데이터 안전

**"앱에서 필요한 사용자 데이터 유형을 수집하거나 공유하나요?" → 아니요**

근거(코드에서 확인한 사실):

| 확인 항목 | 결과 |
|---|---|
| 분석·광고 SDK | 없음 (Firebase·GA·AdMob·Sentry 등 전무) |
| 안드로이드 권한 | **0개** — AndroidManifest 에 선언된 권한 없음 |
| 외부 전송 | 없음. `championsbattledata.com` 에서 공개 자료를 **읽기만** 함 |
| 로컬 저장 | 선택한 대전 형식, 통계 캐시 — 기기 밖으로 안 나감 |

"데이터가 전송 중에 암호화되나요?" → 예 (전부 HTTPS)

### 광고

**"앱에 광고가 포함되어 있나요?" → 아니요**

### 콘텐츠 등급

설문에서 전부 "아니요"로 답하면 된다 — 폭력·성적 콘텐츠·욕설·약물·도박·사용자 간

## 4. 업로드 후 반드시 할 일 — 인증서 지문 추가

**이걸 빼먹으면 앱이 주소창이 보이는 채로 뜬다.** Play 앱 서명을 쓰면 구글이 자기 키로
다시 서명하므로, 기기에서 대조되는 지문이 우리 업로드 키가 아니게 된다.

1. AAB 업로드 → **설정 → 앱 서명**
2. **앱 서명 키 인증서**의 SHA-256 지문 복사
3. `public/.well-known/assetlinks.json` 의 배열에 **추가** (기존 것은 지우지 말 것)
4. 커밋·푸시 → 자동 배포
5. 앱 재설치 후 주소창이 사라졌는지 확인
